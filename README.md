- **03 AI 프로젝트**: 부품 발주 시점 대시보드, PharmaFlow Bio, 안물어(피싱 대응 훈련). 단계마다 문제를 어떻게 다시 정의했는지와 실제 화면.
- **04 LS 여정**: 바이브코딩 기초부터 프로젝트3까지, 단계마다 달라진 점과 증거, 내가 한 일 / 팀 / Claude.
- **02 경력과 학력**: 코스맥스 연구소 경영과 해외영업, 사노피 파스퇴르 마케팅 인턴.
